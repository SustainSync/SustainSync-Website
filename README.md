# SustainSync

A senior computing project focused on sustainability solutions through technology.

## 📁 Repository Structure

```
SustainSync/
├── .github/workflows/    # GitHub Actions for deployment
└── SustainSync-Website/  # Project website (React + TypeScript)
```

## 🌐 Website

The SustainSync website is built with React, TypeScript, and Material-UI. Visit the [SustainSync-Website](./SustainSync-Website) directory for more information.

**Live Site**: [https://sustainsync.github.io/SustainSync-Website/](https://sustainsync.github.io/SustainSync-Website/)

## 🚀 Quick Start

```bash
# Navigate to the website directory
cd SustainSync-Website

# Install dependencies
npm install

# Run development server
npm run dev
```

## 📦 Deployment

The website automatically deploys to GitHub Pages via GitHub Actions when changes are pushed to the `main` branch.
