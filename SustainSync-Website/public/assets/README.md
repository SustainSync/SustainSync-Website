# Assets Directory

Place team member photos and other static assets here.

## Team Member Photos

To add team member photos:
1. Add image files to this directory (e.g., `member1.jpg`, `member2.jpg`)
2. Update the `avatar` property in `src/pages/About.tsx` with the path:
   ```typescript
   avatar: '/SustainSync-Website/assets/member1.jpg'
   ```

Recommended image specifications:
- Format: JPG or PNG
- Size: 300x300px or larger (square aspect ratio)
- File size: Under 500KB for optimal performance
